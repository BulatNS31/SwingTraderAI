# User Interface

## Существующие / ожидаемые страницы (подтверждено документацией и API)

- **Authentication** (signup / login) — backend реализован в `api/v1/auth.py`
- **Dashboard** — watchlist + latest signals (watchlist endpoints exist)
- **Tickers** — поиск/создание тикеров (`tickers.py`)
- **Watchlist** — `api/v1/watchlist.py`
- **Settings** — profile / telegram connect (fields in User model)
