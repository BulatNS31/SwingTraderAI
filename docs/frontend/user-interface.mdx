# Пользовательский интерфейс

Frontend-приложение построено вокруг авторизованных экранов продукта, а не одной статической страницы.

## Разделы, доступные через маршрутизацию

Дерево маршрутов включает:

- страницы аутентификации;
- главную панель управления (Dashboard);
- страницы обзора рынка и аналитики;
- список отслеживаемых инструментов (Watchlist);
- страницы портфеля;
- страницы с подробной информацией по тикерам;
- административные разделы.

## Связанные backend API

Эти страницы взаимодействуют с backend через соответствующие API-маршруты, включая:

- маршруты аутентификации;
- маршруты работы с тикерами;
- маршруты Watchlist;
- маршруты портфеля и пользователей.

## Статус реализации

В рамках этой документации подтверждены общая архитектура пользовательского интерфейса и структура маршрутов.

При этом не утверждается, что каждая страница и каждая функция полностью завершены в текущем состоянии репозитория.
