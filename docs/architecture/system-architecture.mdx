# System Architecture

```
┌─────────────┐     ┌─────────────┐
│  Frontend   │     │  Telegram   │
│  (Vite SPA) │     │    Bot      │
└──────┬──────┘     └──────┬──────┘
       │                   │
       └─────────┬─────────┘
                 │
          ┌──────▼──────┐
          │   FastAPI   │
          │   Backend   │
          └──────┬──────┘
                 │
    ┌────────────┼────────────┐
    │            │            │
┌───▼───┐   ┌────▼────┐  ┌────▼────┐
│Postgres│   │  Redis  │  │   LLM   │
│        │   │         │  │Provider │
└────────┘   └────┬────┘  └─────────┘
                  │
            ┌─────▼─────┐
            │  Celery / │
            │ APScheduler│
            └───────────┘
```

## Описание

- Пользователь взаимодействует через Frontend и Telegram.
- API обрабатывает запросы, использует сервисы/репозитории для работы с БД.
- Background worker (Celery/APScheduler) выполняет периодические задачи: сбор данных, расчёт индикаторов, генерация дайджеста и отправка уведомлений.
- LLM provider вызывается для объяснений/интерпретаций; используйте кэш и бюджетный fallback (см. раздел AI Layer).
