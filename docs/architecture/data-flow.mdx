# Data Flow

## Market Data ingestion

Источники: yfinance (MOEX), ccxt (crypto) — смотрите `pyproject.toml` и модули в `swingtraderai/services` если они присутствуют.

## Storage

Данные свечей сохраняются в таблице `MarketData` (см. `swingtraderai/db/models/market.py`).

## Technical Analysis

Индикаторы рассчитываются (pandas_ta, pandas) — результаты могут сохраняться или рассчитываться on-demand.

## Signal Detection

Правила (rule-based) анализируют индикаторы и помечают потенциальные сетапы.

## AI Analysis

LLM получает подготовленную информацию (цель — объяснение/контекст) и возвращает текстовые объяснения.

## Result delivery

Сигналы и объяснения доступны через API; уведомления отправляются в Telegram.

## Примечание

Если провайдер данных недоступен — система должна использовать кэшированные данные и помечать статусы как stale.
