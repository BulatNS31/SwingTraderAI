# Testing

Pytest настроен (`pyproject.toml`, pytest settings).

## Запуск тестов

```bash
poetry run pytest
```

## Маркеры

`asyncio`, `slow`, `db` — определены в `pyproject.toml`.

## Структура

В проекте есть `tests/` — проверьте структуру и ключевые тесты.
