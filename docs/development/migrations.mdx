# Migrations

Alembic config находится в `alembic/` и `alembic.ini`.

## Создание миграции

```bash
alembic revision --autogenerate -m "message"
```

## Применение миграций

```bash
alembic upgrade head
```

## Локальная работа

Для локальной работы убедитесь, что `DATABASE_URL` установлен и Alembic видит models (`env.py` должен импортировать `Base`).
