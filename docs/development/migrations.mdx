# Миграции

В репозитории предусмотрена поддержка миграций базы данных с помощью Alembic. Используйте Alembic при изменении моделей или структуры базы данных.

## Создание миграции

```bash
alembic revision --autogenerate -m "описание изменения"
````

## Применение миграций

```bash
alembic upgrade head
```

## Важное требование

Переменная `DATABASE_URL` должна указывать на корректную базу данных, а окружение миграций должно импортировать SQLAlchemy metadata из моделей приложения.

## Рекомендации по работе

Перед тем как считать изменения схемы завершёнными, убедитесь, что сгенерированная миграция соответствует предполагаемым изменениям моделей и что приложение успешно запускается с обновлённой базой данных.
