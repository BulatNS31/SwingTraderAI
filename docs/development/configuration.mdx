# Configuration / Environment variables

Ниже — найденные в коде переменные конфигурации (основываясь на `swingtraderai/core/config.py` и README). Не включаю секреты.

| Variable                      | Required | Description                  | Default      |
|-------------------------------|----------|------------------------------|--------------|
| `SECRET_KEY`                  | yes      | JWT and other secrets        | (no default) |
| `ALGORITHM`                   | yes      | JWT algorithm                | (no default) |
| `DATABASE_URL`                | yes      | SQLAlchemy database URL      | (no default) |
| `REDIS_URL`                   | yes      | Redis connection string      | (no default) |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | no       | Access token expiry          | 30           |
| `REFRESH_TOKEN_EXPIRE_DAYS`   | no       | Refresh token expiry         | 7            |
| `CORS_ALLOWED_ORIGINS`        | no       | List of allowed origins      | `[]`         |

README also mentions:

- `TELEGRAM_BOT_TOKEN`
- `ANTHROPIC_API_KEY` (example)
- LLM provider keys (`OPENAI_API_KEY` etc.)
