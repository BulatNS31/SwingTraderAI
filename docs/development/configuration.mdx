# Конфигурация

Приложение считывает конфигурацию из файла `.env` с помощью `pydantic-settings`, используя `swingtraderai/core/config.py`.

## Обязательные настройки

| Переменная | Обязательная | Значение по умолчанию | Назначение | Где используется |
| --- | --- | --- | --- | --- |
| `SECRET_KEY` | Да | отсутствует | Ключ для подписи JWT | `core/security.py` |
| `ALGORITHM` | Да | отсутствует | Алгоритм JWT | `core/security.py` |
| `DATABASE_URL` | Да | отсутствует | Строка асинхронного подключения к PostgreSQL | `db/session.py` |
| `REDIS_URL` | Да | отсутствует | Redis и брокер/backend Celery | `celery.py` |

## Необязательные настройки

| Переменная | Обязательная | Значение по умолчанию | Назначение | Где используется |
| --- | --- | --- | --- | --- |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Нет | `30` | Время жизни токена доступа | `core/config.py` |
| `REFRESH_TOKEN_EXPIRE_DAYS` | Нет | `7` | Время жизни токена обновления | `core/config.py` |
| `CORS_ALLOWED_ORIGINS` | Нет | `[]` | Список разрешённых источников для CORS | `main.py` |

## Примечания

- В настоящее время в корне репозитория отсутствует файл `.env.example`.
- Код не содержит прямой ссылки на токен Telegram-бота или внешний ключ LLM в runtime-конфигурации.
- Некоторые примеры в README содержат переменные для Telegram или AI-провайдеров, однако фактический класс `Settings` в `swingtraderai/core/config.py` объявляет только переменные, указанные выше.

## Пример

```env
SECRET_KEY=replace-with-a-long-secret
ALGORITHM=HS256
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/swingtrader
REDIS_URL=redis://localhost:6379/0
ACCESS_TOKEN_EXPIRE_MINUTES=30
REFRESH_TOKEN_EXPIRE_DAYS=7
CORS_ALLOWED_ORIGINS=["http://localhost:5173"]
````
