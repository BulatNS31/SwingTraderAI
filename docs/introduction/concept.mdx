# Концепция

(Адаптировано из CONCEPT-RUS.md и README. Приоритет — код.)

## Основная идея

- Разделение ответственности:
  - **Algorithmic Analysis** — детерминированные математические расчёты (индикаторы)
  - **AI Analysis** — интерпретация контекста (LLM), объяснения и причины для сигналов
  - **Trader** — принимает окончательное решение (продукт не выполняет торговые операции)

## Ключевые элементы

- Технические уровни (support/resistance), ATR, запасы хода (range/volatility) и торговые сетапы — перечислены в документации и реализованы в виде компонентов индикаторов (см. `swingtraderai/services/indicators` если присутствует).
- AI анализ действительно предназначен для интерпретации результатов технической аналитики, а не для замещения математической логики.
